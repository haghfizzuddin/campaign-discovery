# Profile: recruitment-threat

Employment and recruitment themed fraud and malware delivery.

Covers: fake recruiters on LinkedIn/WhatsApp/Telegram, malicious coding
assessments and "take-home" repositories (Contagious Interview, BeaverTail,
InvisibleFerret, OtterCookie), task scams, advance-fee and equipment-check job
offers, identity harvesting through fake onboarding, and DPRK-style fake IT
workers.

Files:

- `lexicon.yaml` — topic and harm term weights, campaign names, lure keywords,
  lure-type and stage rules, impersonated brands and their cue rules, pivot query
  templates, report labels, ignored domains, per-venue weights and thresholds.
- `sources.yaml` — subreddits and queries (Arctic Shift), GitHub searches, RSS
  feeds, Mastodon tags, URLhaus tag filters, pivot depth, enrichment and
  clustering settings, feature specificity map.

This profile grew from the first live run on 2026-09-06 (877 public items,
127 cases, one strongly clustered Contagious Interview dropper).
